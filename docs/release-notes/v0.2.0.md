# CREATOR.EXE v0.2.0 — Tamster identity + Channel DNA (Phase 2)

Phase 2 preserves the **same app ID and SQLite database** as v0.1.0 and adds an append-only schema v2 migration.

## Included
- Editable creator-owned **Tamster** channel identity with the exact, informal description from the user; laser-eye-cat avatar and pink Y2K collage are stored as aesthetic notes, NOT invented/AI images.
- **Gaming-first content focus** (85% gaming, occasional gaming-adjacent tech) with Gaming only, Gaming + tech, Variety, and Outside my niche alternatives; the interest and Tonight modes respect the chosen boundary.
- Additional real gaming idea premises that leave creative direction and editing entirely with the creator.
- Channel metadata classification no longer calls all uploads Film & media because of "TV" appearing in generic descriptions.
- Channel DNA **Local video evidence** screen: opt-in, local FFprobe/FFmpeg scanning of a creator-owned video (up to the first 90 seconds), detected substantial frame changes/quiet periods, native duration/resolution, SRT/VTT/TXT transcript import, observed thumbnail color palette and hand-written notes.
- New video_forensics SQLite table, backed up and restored with existing data; older backups remain supported.
- New tests for transcript parsing, local evidence merging, backups and content focus; existing Rust and UI tests retained.

## Important limitations
- Local video analysis requires independently installed **FFmpeg and FFprobe** available on PATH. They do not come bundled.
- Objective signal detections are not proof of intentional cuts, comedic timing, captions or editing technique.
- No scraping/downloading YouTube video streams and **no automatic AI analysis**; local original files must be selected explicitly.
- No thumbnail pixel layout reconstruction, frame sampling gallery, full spoken-language transcription, or new YouTube OAuth integration yet.
- No Comedy Engine, Editing Companion or imposed scripted jokes.
- Changing profile display name/description in the app does not automatically modify YouTube itself.

## Upgrade
Back up v0.1.0 through File → Back up data, install v0.2.0 over it, and use docs/ACCEPTANCE.md Phase 2. Avoid downgrading after the database migration unless you restore an older backup.

## Build
This branch is a preview until GitHub Actions successfully runs strict TypeScript, Node tests, Rust tests, and the actual Windows packaging job. Download only the build whose job passes.
