## CREATOR.EXE 0.1.0 — Phase 1: working Windows foundation

First real release. It already helps you go from "no idea" to a planned, packaged video.

### Download
- `CREATOR.EXE_0.1.0_x64-setup.exe`: recommended (per-user install)
- `CREATOR.EXE_0.1.0_x64_en-US.msi`
- `CREATOR.EXE_0.1.0_x64_portable.exe`
- `SHA256SUMS.txt`

Not code-signed: on the SmartScreen prompt choose **More info → Run anyway**.

### What's in it
- **Control Room**: current project and its next action, three ideas, idea inbox, projects in progress, recent research and thumbnails.
- **TONIGHT.EXE**: three low-effort ideas with first five minutes and a minimum viable video. **START THIS VIDEO** creates a filled-in project.
- **Idea Machine**: 8 modes (balanced, tonight, zero budget, deep dive, one-off, series, curiosity, random) plus familiar / adjacent / new / surprise interest, energy/time/budget/recording/size/format/collab/research/direction controls, explainable plus/minus factors, nine kinds of feedback, an inbox and a side-by-side **Compare** (Idea Advisor). No percentages.
- **Video Workshop**: kanban (11 stages) and list views, search, filters, custom status, priority, checklists, research links, project folders from a template, "Open in editor", history, and a **Stuck?** rescue that offers a smaller version instead of more tasks.
- **Research desk**: Wikipedia lookup, sources with publisher/date/last checked, verification status (unchecked / verified / speculation / conflicting), your own conclusions kept separate.
- **Thumbnail Lab**: 7 concept styles built from real editable layers; a layered 1280×720 editor (text, shapes, images, backgrounds, move/resize/rotate/crop, outlines, shadows, opacity, lock/hide, snapping, grid, safe area with timestamp zone, phone-size previews, undo/redo). Exports PNG, SVG, OpenRaster (.ora, opens in Krita with layers) and a native `.cthumb`.
- **Packaging Lab**: Title Lab (10 styles, favorites, compare, clarity checks: length, unclear openings, unbacked claims, clickbait phrases, search relevance), description assembled from your own notes and sources, tags, hashtags, credits, pinned comment, chapter template, disclosure and upload checklists, saved versions, one-click copy.
- **Channel DNA**: import from the public feed (now accepts `@handle`), the YouTube Data API (free key), a YouTube Studio CSV export, or by hand. Preview before merge, dedup by video ID, never overwrites your notes. Library with ratings and "I loved making this"-style flags; patterns with evidence links.
- **Creator Memory**: lasting vs. for-now entries, rejected ideas, reactions that fade. **New:** starts with 19 interests from your brief so the first ideas are personal.
- **Settings & data**: six themes (Midnight 2003 default, Phosphor Green, CRT Amber, Gothic Terminal, Classic Windows Dark, Monochrome Studio), three densities, text scaling, JSON backup/restore with preview and an automatic safety backup, API key kept in Windows Credential Manager (never in backups).

### Changed since the dev builds
- Public-feed import accepts `@TamsterCo` or a channel URL and looks up the UC ID.
- Creator Memory is seeded once from the brief (only when empty; deleting entries is permanent).
- Enjoyment shows `???` instead of an empty meter when there's nothing to go on.
- Packaging Lab lists your projects instead of an empty page.
- Phone-size thumbnail previews no longer overflow the properties panel.
- Small fixes: plural labels, boot notice shown once, safe-area label font.

### Phase 1 exit report
1. **Implemented**: everything above.
2. **Not yet implemented**: Rabbit Hole visual topic map (Phase 4), AI modes (Phase 3), Google OAuth + Analytics screen (Phase 6), transcript/local video analysis and thumbnail-pattern analysis (Phase 2), Asset Vault (Phase 5/6), Canva handoff (Phase 5), notifications.
3. **Automated tests**: 54 node:test cases (channel import, merge/dedup, ideas & diversity, preference learning, projects, backup/restore, migrations, packaging, titles, thumbnail layers, undo/redo, OpenRaster export) + 10 Rust unit tests (`cargo test --lib`: SQLite atomic batches and persistence, safe folder creation, path-escape rejection, secret-name validation). All passing on CI.
4. **Strict TypeScript**: `tsc --noEmit` in CI (see the run for this commit).
5. **Rust**: compiled and tested on `windows-latest` in CI.
6. **Windows build**: NSIS + MSI + portable produced by the `windows` job.
7. **Commit**: the release tag `v0.1.0` points at it.
8. **Installer location**: this release's assets.
9. **Known limitations**: unsigned installers; the public feed lists only the 15 newest uploads and no lengths (use a free Data API key for all of them); concept fonts use fonts installed on Windows; no AI.
10. **Upgrade**: run the new installer over the old one. Data in `%APPDATA%\com.tommyphelps.creatorexe` is migrated automatically; back up first via File → Back up data… if you like.
11. **Acceptance tests**: [docs/ACCEPTANCE.md](https://github.com/TommyPhelps/creator-exe/blob/creator-exe-v1/docs/ACCEPTANCE.md).
